# 八字解读与紫微斗数

一个基于中国传统命理学的网页应用，结合生辰八字和紫微斗数进行详细解读。

## 项目简介

本项目提供了一个完整的八字排盘和紫微斗数解读系统，用户只需输入出生年月日时和性别，即可获得详细的命理分析。

## 功能特点

### 1. 生辰八字排盘
- **年柱**：以立春为界，准确计算年干支
- **月柱**：以节气（十二节）为界，使用五虎遁口诀
- **日柱**：使用高氏日柱公式，精确计算日干支
- **时柱**：使用五鼠遁口诀，考虑子时特殊处理

### 2. 周易卦象分析
- 根据生辰八字生成对应的六十四卦
- 展示卦象图形（阳爻/阴爻）
- 提供详细的卦象解读

### 3. 紫微斗数命盘
- **命宫与身宫**：根据出生时间确定
- **十二宫位**：命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾厄宫、迁移宫、交友宫、事业宫、田宅宫、福德宫、父母宫
- **主星分布**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **四化星**：化禄、化权、化科、化忌

### 4. 详细解读内容
- **性格分析**：根据命宫主星分析性格特点
- **感情婚姻**：分析感情运势和配偶特点
- **财运分析**：分析财运状况和理财建议
- **事业发展**：分析事业方向和发展建议
- **综合建议**：结合命盘特点给出人生指导

## 技术实现

### 核心算法

#### 八字排盘算法
1. **年柱计算**：
   - 以立春为年份分界点
   - 公式：天干 `(年份-4) % 10`，地支 `(年份-4) % 12`

2. **月柱计算**：
   - 以节气（十二节）为月份分界
   - 地支：立春→寅、惊蛰→卯、清明→辰...
   - 天干：五虎遁口诀
     - 甲己之年丙作首
     - 乙庚之年戊为头
     - 丙辛之岁寻庚上
     - 丁壬壬寅顺水流
     - 戊癸何方发，甲寅之上好追求

3. **日柱计算**：
   - 高氏日柱公式（1900-2100年适用）
   - 23:00后出生按第二天计算

4. **时柱计算**：
   - 五鼠遁口诀
     - 甲己还加甲
     - 乙庚丙作初
     - 丙辛从戊起
     - 丁壬庚子居
     - 戊癸何方发，壬子是真途

#### 紫微斗数算法
1. **命宫计算**：
   - 寅宫起正月，顺数生月宫
   - 逆数生时为命宫

2. **身宫计算**：
   - 寅宫起正月，顺数生月宫
   - 顺数生时是身宫

3. **五行局**：
   - 根据命宫干支的纳音五行确定
   - 水二局、木三局、金四局、土五局、火六局

4. **四化星**：
   - 甲：廉破武阳
   - 乙：机梁紫阴
   - 丙：同机昌廉
   - 丁：阴同机巨
   - 戊：贪阴右机
   - 己：武贪粱曲
   - 庚：阳武阴同
   - 辛：巨阳曲昌
   - 壬：梁紫左武
   - 癸：破巨阴贪

## 紫微斗数基础知识

### 十二宫位含义

1. **命宫**：代表人的核心性格、天赋特质、外在表现，是命盘的核心。
2. **兄弟宫**：代表兄弟姐妹关系、同辈合作、竞争态势。
3. **夫妻宫**：代表婚姻感情、配偶情况、两性关系。
4. **子女宫**：代表子女情况、下属晚辈、创意表现。
5. **财帛宫**：代表财运状况、理财能力、物质欲望。
6. **疾厄宫**：代表身体健康、潜在疾病、心理状态。
7. **迁移宫**：代表外出发展、人际形象、机遇变化。
8. **交友宫**：代表朋友关系、社交网络、助力情况。
9. **事业宫**：代表事业发展、职业选择、社会地位。
10. **田宅宫**：代表家庭房产、固定资产、内心世界。
11. **福德宫**：代表精神享受、福报运气、心态情绪。
12. **父母宫**：代表父母长辈、学业基础、名誉名声。

### 十四主星特点

#### 紫微星系（北斗主星）
- **紫微**：帝星，尊贵、领导力、自尊心强
- **天机**：智慧星，聪明、灵活、多变
- **太阳**：官贵星，光明、热情、事业心强
- **武曲**：财星，坚毅、务实、财运好
- **天同**：福星，温和、享受、福气好
- **廉贞**：次桃花星，复杂、桃花、约束

#### 天府星系（南斗主星）
- **天府**：府库星，稳重、包容、储蓄
- **太阴**：财星，温柔、内敛、阴性力量
- **贪狼**：桃花星，欲望、才华、机遇
- **巨门**：口舌星，口才、是非、观察
- **天相**：印星，稳重、辅助、责任
- **天梁**：荫星，长寿、荫蔽、智慧
- **七杀**：将星，魄力、冲劲、竞争
- **破军**：耗星，破坏、创新、变动

### 四化星含义
- **化禄**：代表财禄、机遇、享受、贵人运强
- **化权**：代表权力、能力、行动力、领导力强
- **化科**：代表名声、智慧、考试运、贵人相助
- **化忌**：代表阻碍、困扰、变动、需要谨慎

## 文化背景

中国传统命理学有着数千年的历史，是中华文化的重要组成部分。八字（四柱预测学）和紫微斗数是其中最具代表性的两种命理体系。

- **八字**：起源于唐代，以出生年月日时的天干地支为基础，通过五行生克制化来分析命运。
- **紫微斗数**：相传为北宋陈抟所创，以紫微星为帝王星，将108颗星曜排布在十二宫位中进行分析。

这些传统文化知识蕴含着古人对生命、自然和社会的深刻观察与思考，值得我们学习和传承。
