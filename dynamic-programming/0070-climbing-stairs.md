# 70. 爬楼梯 (Climbing Stairs)

## 题目信息

- **题目编号**: 70
- **题目名称**: 爬楼梯
- **英文名称**: Climbing Stairs
- **题目标签**: 记忆化、数学、动态规划
- **题目难度**: 简单
- **题目链接**: https://leetcode.cn/problems/climbing-stairs/

## 题目描述

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶？

## 示例

### 示例 1
```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶：
1. 1 步 + 1 步
2. 2 步
```

### 示例 2
```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶：
1. 1 步 + 1 步 + 1 步
2. 1 步 + 2 步
3. 2 步 + 1 步
```

## 约束条件

- 1 <= n <= 45

### 初步思考

当我们第一次看到这道题时，可能会尝试枚举所有可能的方法。但这种方法很快就会变得不可行——当 n 增大时，组合数会爆炸式增长。

让我们换一种思路：假设你已经站在第 n-1 阶楼梯上，你最后一步只能走 1 阶到达终点；或者你站在第 n-2 阶楼梯上，最后一步走 2 阶到达终点。

这意味着：**到达第 n 阶的方法数 = 到达第 n-1 阶的方法数 + 到达第 n-2 阶的方法数**

这不正是斐波那契数列吗！

### 方法一：递归（最直观但效率最低）

#### 思路

根据递推关系式，直接写出递归形式：
- f(n) = f(n-1) + f(n-2)

#### 复杂度分析

- 时间复杂度：O(2^n)，因为存在大量重复计算
- 空间复杂度：O(n)，递归栈深度

#### 缺点

当 n 较大时（如 n = 40），会严重超时。因此我们需要更高效的写法。

---

### 方法二：记忆化递归（自顶向下 DP）

#### 思路

仍然使用递归思路，但用一个数组保存中间结果，避免重复计算。

#### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

#### 思想

递归 + 记忆化 = 动态规划的雏形。

### 方法三：动态规划（自底向上）【推荐学习】

#### 动态规划图示（以 n=5 为例）

**自底向上的计算过程：**

```
初始状态：
  索引:    0   1   2   3   4   5
         ┌───┬───┬───┬───┬───┬───┐
  dp:    │ 0 │ 1 │ 2 │ ? │ ? │ ? │
         └───┴───┴───┴───┴───┴───┘
              ↑   ↑
              │   │
           dp[1] dp[2]
            已知  已知

第 1 步：计算 dp[3] = dp[2] + dp[1] = 2 + 1 = 3
  索引:    0   1   2   3   4   5
         ┌───┬───┬───┬───┬───┬───┐
  dp:    │ 0 │ 1 │ 2 │ 3 │ ? │ ? │
         └───┴───┴───┴───┴───┴───┘
                      ↑
                      │
                    dp[3]

第 2 步：计算 dp[4] = dp[3] + dp[2] = 3 + 2 = 5
  索引:    0   1   2   3   4   5
         ┌───┬───┬───┬───┬───┬───┐
  dp:    │ 0 │ 1 │ 2 │ 3 │ 5 │ ? │
         └───┴───┴───┴───┴───┴───┘
                          ↑
                          │
                        dp[4]

第 3 步：计算 dp[5] = dp[4] + dp[3] = 5 + 3 = 8
  索引:    0   1   2   3   4   5
         ┌───┬───┬───┬───┬───┬───┐
  dp:    │ 0 │ 1 │ 2 │ 3 │ 5 │ 8 │
         └───┴───┴───┴───┴───┴───┘
                              ↑
                              │
                            结果！
```

**状态转移关系图：**

```
         ┌─────────────────────────────────────┐
         │           状态转移方程               │
         │      dp[i] = dp[i-1] + dp[i-2]     │
         └─────────────────────────────────────┘

                    到达第 i 阶
                         │
          ┌──────────────┴──────────────┐
          │                               │
          ▼                               ▼
    从第 i-1 阶走 1 步            从第 i-2 阶走 2 步
          │                               │
          ▼                               ▼
      dp[i-1]                         dp[i-2]
          │                               │
          └───────────────┬───────────────┘
                          │
                          ▼
                    dp[i] = dp[i-1] + dp[i-2]
```

#### 思路

递归可以从"上往下"求解；动态规划则是"自底向上"求解。

我们知道：
- f(1) = 1
- f(2) = 2
- f(3) = f(2) + f(1)
- ...
- f(n) = f(n-1) + f(n-2)

所以我们从 1 计算到 n。

#### 状态定义

dp[i]：表示到达第 i 阶台阶的不同走法数量。

#### 转移方程

当 i >= 3：
```
dp[i] = dp[i-1] + dp[i-2]
```

#### 初始化（边界）

- dp[1] = 1：到 1 阶只有一种（1）
- dp[2] = 2：到 2 阶两种（1+1，2）

#### 推导过程演示

以 n = 5 为例：

```
dp[1] = 1
dp[2] = 2
dp[3] = dp[2] + dp[1] = 2 + 1 = 3
dp[4] = dp[3] + dp[2] = 3 + 2 = 5
dp[5] = dp[4] + dp[3] = 5 + 3 = 8
```

#### 算法步骤

1. 处理特殊情况：如果 n <= 2，直接返回 n
2. 初始化 dp[1] = 1，dp[2] = 2
3. 从 i = 3 到 n 遍历：
   - 计算 dp[i] = dp[i-1] + dp[i-2]
4. 返回 dp[n]

#### 复杂度分析

- 时间复杂度：O(n)，需要计算到第 n 项
- 空间复杂度：O(n)，需要存储整个 dp 数组

### 方法四：空间优化（滚动数组）【最推荐】

#### 空间优化图示（以 n=5 为例）

**对比：动态规划数组 vs 滚动数组**

```
动态规划数组（空间 O(n)）：
┌───┬───┬───┬───┬───┬───┐
│ 0 │ 1 │ 2 │ 3 │ 5 │ 8 │  ← 需要存储所有值
└───┴───┴───┴───┴───┴───┘
    ↑   ↑   ↑   ↑   ↑
    └───┴───┴───┴───┘
         6 个位置

滚动数组（空间 O(1)）：
只需要 2 个变量！
┌──────────┐    ┌──────────┐
│   prev   │    │   curr   │
│ dp[i-2]  │    │ dp[i-1]  │
└──────────┘    └──────────┘
     ↑                ↑
     └──────┬─────────┘
            ▼
       next = prev + curr
```

**滚动数组完整计算过程（n=5）：**

```
初始状态：
  prev = 1  (代表 dp[1])
  curr = 2  (代表 dp[2])

  图示：
  ┌────────┐      ┌────────┐
  │ prev=1 │ ───▶ │ curr=2 │
  │ dp[1]  │      │ dp[2]  │
  └────────┘      └────────┘

═══════════════════════════════════

第 1 次循环（i=3，计算 dp[3]）：
  next = prev + curr = 1 + 2 = 3
  
  更新变量：
  prev = curr  → prev = 2
  curr = next  → curr = 3

  图示：
  ┌────────┐      ┌────────┐
  │ prev=2 │ ───▶ │ curr=3 │
  │ dp[2]  │      │ dp[3]  │
  └────────┘      └────────┘

═══════════════════════════════════

第 2 次循环（i=4，计算 dp[4]）：
  next = prev + curr = 2 + 3 = 5
  
  更新变量：
  prev = curr  → prev = 3
  curr = next  → curr = 5

  图示：
  ┌────────┐      ┌────────┐
  │ prev=3 │ ───▶ │ curr=5 │
  │ dp[3]  │      │ dp[4]  │
  └────────┘      └────────┘

═══════════════════════════════════

第 3 次循环（i=5，计算 dp[5]）：
  next = prev + curr = 3 + 5 = 8
  
  更新变量：
  prev = curr  → prev = 5
  curr = next  → curr = 8

  图示：
  ┌────────┐      ┌────────┐
  │ prev=5 │ ───▶ │ curr=8 │
  │ dp[4]  │      │ dp[5]  │
  └────────┘      └────────┘
                         ↑
                         │
                       结果！
═══════════════════════════════════

最终结果：curr = 8
```

**滚动数组原理图示：**

```
计算 dp[i] 时，只需要 dp[i-1] 和 dp[i-2]：

        ┌─────────────────────────────────┐
        │         计算 dp[i]              │
        │     (不需要其他历史数据)         │
        └─────────────────────────────────┘
                      │
        ┌─────────────┴─────────────┐
        ▼                           ▼
   ┌─────────┐                 ┌─────────┐
   │  curr   │                 │  prev   │
   │ dp[i-1] │                 │ dp[i-2] │
   └─────────┘                 └─────────┘
        │                           │
        └─────────────┬─────────────┘
                      ▼
              ┌──────────────┐
              │ next = curr  │
              │      + prev  │
              └──────────────┘
                      │
                      ▼
              ┌──────────────┐
              │  滚动更新:    │
              │  prev = curr │
              │  curr = next │
              └──────────────┘
```

#### 思路

观察动态规划的递推公式 dp[i] = dp[i-1] + dp[i-2]，我们发现计算 dp[i] 只需要前两项的值。因此我们可以用两个变量滚动更新，而不需要整个数组。

#### 算法步骤

1. 处理特殊情况：如果 n <= 2，直接返回 n
2. 初始化 prev = 1（dp[i-2]），curr = 2（dp[i-1]）
3. 从 i = 3 到 n 遍历：
   - 计算 next = prev + curr
   - 更新 prev = curr，curr = next
4. 返回 curr

#### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，只使用常数个变量

#### 优点

这是最推荐的写法，高效简洁，面试中展示空间优化能力会加分。

### 方法五：数学公式（闭式解法）【进阶】

#### 思路

斐波那契数列有通项公式：

```
F(n) = (1/√5) × [((1+√5)/2)^(n+1) - ((1-√5)/2)^(n+1)]
```

因此可以直接用数学公式计算结果。

#### 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

#### 缺点

浮点数运算存在微小误差，但在 n ≤ 45 时完全安全。

## 代码实现

### Python 实现

```python
class Solution:
    # 方法四：空间优化的动态规划（推荐）
    def climbStairs(self, n: int) -> int:
        """
        计算爬楼梯的方法数
        
        Args:
            n: 楼梯阶数
            
        Returns:
            不同的爬楼方法数
        """
        # 基础情况
        if n <= 2:
            return n
        
        # 空间优化的动态规划
        prev, curr = 1, 2  # dp[1], dp[2]
        for _ in range(3, n + 1):
            next_val = prev + curr
            prev, curr = curr, next_val
        
        return curr
    
    # 方法三：完整数组的动态规划
    def climbStairsWithDP(self, n: int) -> int:
        if n <= 2:
            return n
        
        dp = [0] * (n + 1)
        dp[1], dp[2] = 1, 2
        
        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
        
        return dp[n]
    
    # 方法五：数学公式
    def climbStairsMath(self, n: int) -> int:
        import math
        sqrt5 = math.sqrt(5)
        fibn = math.pow((1 + sqrt5) / 2, n + 1) - math.pow((1 - sqrt5) / 2, n + 1)
        return int(round(fibn / sqrt5))
```

### Java 实现

```java
class Solution {
    // 方法四：空间优化的动态规划（推荐）
    public int climbStairs(int n) {
        // 基础情况
        if (n <= 2) {
            return n;
        }
        
        // 空间优化的动态规划
        int prev = 1;  // dp[i-2]
        int curr = 2;  // dp[i-1]
        
        for (int i = 3; i <= n; i++) {
            int next = prev + curr;
            prev = curr;
            curr = next;
        }
        
        return curr;
    }
    
    // 方法三：完整数组的动态规划
    public int climbStairsWithDP(int n) {
        if (n <= 2) {
            return n;
        }
        
        int[] dp = new int[n + 1];
        dp[1] = 1;
        dp[2] = 2;
        
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        
        return dp[n];
    }
}
```

## 解法对比总结

| 解法 | 思想 | 时间复杂度 | 空间复杂度 | 是否推荐 |
|------|------|-----------|-----------|---------|
| 递归 | 暴力搜索 | O(2^n) | O(n) | ❌ 极慢 |

## 总结与收获

### 知识点

1. **动态规划基本思想**：将问题分解为重叠子问题，通过存储中间结果避免重复计算
2. **状态转移方程**：dp[i] = dp[i-1] + dp[i-2]
3. **空间优化技巧**：滚动数组，只保存需要的前两个状态
4. **斐波那契数列**：本题与斐波那契数列同构

### 易错点

1. **边界条件处理**：n = 0, 1, 2 的情况需要特别注意
2. **初始值设置**：dp[0] 有时被设为 1（站在地面），有时不使用，要统一
3. **循环起始值**：从 i = 3 开始遍历，而不是 i = 0 或 i = 1

### 优化思路

1. **时间优化**：从递归 O(2^n) 到动态规划 O(n)，再到数学公式 O(1)
2. **空间优化**：从数组 O(n) 到滚动变量 O(1)

### 类似题目扩展

这个问题的本质是：**从起点到终点的路径数问题，每步可选择 1 或 2**。

可以类比到很多动态规划问题：

- [62. 不同路径](https://leetcode.cn/problems/unique-paths/)：二维的路径计数问题
